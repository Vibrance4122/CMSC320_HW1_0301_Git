Q1: Why might we consider using Git?

Answer: 
Git lets you track changes to your code and go back to earlier versions if something breaks. 
It also makes teamwork easier since people can work on the same project without overwriting each other's changes. 
You can also use branches to test new ideas without affecting the main code.

Q2: What field could data science be applied to? Give an Example.

Answer: 
Data science can be applied to healthcare. For example, hospitals can analyze patient data to identify trends, 
predict health risks, and improve treatment decisions.


Q3: What is the difference between Merging and Rebasing?

Answer:
Merging combines two branches by creating a new commit, while rebasing moves a branch's commits on top of another 
branch. Merging keeps the original history, while rebasing creates a cleaner history.
